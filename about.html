[ Project name ] is an evidence map of the published research on the USDA Conservation Reserve Program (CRP). How the dataset was built

We compiled roughly [ X,000 ] publications spanning [ N ] journals and other venues, collected through the OpenAlex API — an open, comprehensive catalog of the world's scholarly works. Each record is pulled programmatically, de-duplicated, and refreshed as new work is indexed, giving a single, consistently structured view of the CRP literature.

For every publication we capture:

  • Bibliographic details — title, DOI, type, publication date, and venue
  • Authors & institutions — names, affiliations, and US state of origin
  • Topics & keywords — the OpenAlex topic hierarchy plus a CRP theme
  • Open access — whether the work is freely available, and by which route
  • Citation impact — citation counts and field-weighted citation impact
  • Funding — acknowledged funders and awards
  • Indexing — the databases and platforms that list each work
  • Abstract — reconstructed full text for searching
